# مدوّنة وعي — Mindful Blog

مدوّنة ويب ثنائية اللغة (عربي RTL / إنجليزي LTR) مبنية بـ HTML + CSS + Tailwind CSS + JavaScript خالص،
بدون أي إطار عمل أو قاعدة بيانات. المواضيع: علم النفس، تطوير الذات، لغة الجسد، العلاقات الإنسانية، الإنتاجية.

## هيكل الملفات

```
mindful-blog/
├── index.html          الصفحة الرئيسية (ترويحة + مختارات + أحدث المقالات + نشرة بريدية)
├── article.html        صفحة عرض المقال (مريحة للعين + مساحات AdSense + جدول محتويات)
├── quizzes.html        الاختبارات الذاتية السريعة (3 اختبارات × 6 أسئلة + نتيجة فورية)
├── challenge.html      تحدّي الـ 21 يوماً (3 أسابيع + مهمة يومية + حفظ التقدّم)
├── bodylanguage.html   مكتبة لغة الجسد المرئية (8 بطاقات مصوّرة قابلة للتوسيع)
├── ask.html            زاوية سؤال وجواب مجهولة (نموذج استشارة سرّي + أسئلة منشورة)
├── about.html          من نحن (ثنائية اللغة)
├── privacy.html        سياسة الخصوصية (متوافقة مع متطلبات Google AdSense)
├── robots.txt          للسماح بأرشفة الموقع
├── sitemap.xml         خريطة الموقع (بدّل example.com بنطاقك)
└── assets/
    ├── css/style.css   الأنماط المكمّلة لـ Tailwind (بطاقات، مقال، ترويسة، تذييل، أدوات)
    ├── images/         الصور البارزة للمقالات + صور لغة الجسد (1200×800 JPEG)
    └── js/
        ├── i18n.js     قاموس الترجمة + تبديل اللغة والاتجاه (RTL/LTR) + حفظ التفضيل
        ├── content.js  قاعدة بيانات المقالات (11 مقالاً كاملاً باللغتين)
        ├── tools-data.js بيانات الأدوات (اختبارات، تحدّي، لغة جسد، أسئلة) باللغتين
        ├── tools.js    محرّكات الأدوات التفاعلية الأربعة
        └── main.js     بناء الترويسة/التذييل/البطاقات/صفحة المقال/البحث/الفلاتر
```

## التشغيل محلياً

```bash
cd mindful-blog
python3 -m http.server 8123
# ثم افتح: http://localhost:8123
```

أو افتح `index.html` مباشرة في المتصفح (يعمل بدون خادم).

## كيف يعمل تبديل اللغة؟

- زر التبديل موجود في أعلى كل صفحة (الترويسة) ويظهر أيضاً في القائمة المنسدلة على الجوال.
- عند التبديل يتغيّر: اتجاه الصفحة (`dir="rtl"` / `dir="ltr"`)، ولغة الواجهة (`lang`)،
  والخطوط (Tajawal/Cairo للعربية، Inter/Lora للإنجليزية)، وكل النصوص عبر قاموس `I18N` في `i18n.js`.
- تفضيل الزائر يُحفظ في `localStorage`، ويمكن فرض اللغة عبر الرابط: `?lang=ar` أو `?lang=en`.
- المقالات مخزّنة بنسختين كاملتين في `content.js`، وتُرسم النسخة المطابقة للغة الحالية.

## المشاهد الخلفية التفاعلية (Parallax)

كل صفحة تحمل «مشهداً خلفياً» ثابتاً من أربع كتل ضوئية تتحرك بسرعات مختلفة مع التمرير،
ويتغيّر لونها ونمط حركتها وسرعتها حسب موضوع الصفحة عبر `data-theme` على `<body>`:

| الموضوع | `data-theme` | الألوان | نمط الحركة | سرعة التمرير |
|---|---|---|---|---|
| الافتراضي (الرئيسية/من نحن/الخصوصية) | `default` | بنفسجي/كهرماني | تنفّس متوسط | 0.30 |
| علم النفس | `psychology` | لافندر هادئ | تنفّس بطيء جداً (15ث) | 0.13 |
| تطوير الذات | `selfdev` | كهرماني دافئ | صعود حيوي سريع (4.5–6.5ث) | 0.60 |
| لغة الجسد | `bodylanguage` | أخضر مزرق | تمايل أفقي متموّج | 0.32 |
| العلاقات | `relationships` | وردي | دوران مداري متعاكس | 0.22 |
| الإنتاجية | `productivity` | أزرق سماوي | نبض منتظم (دورة عمل/راحة) | 0.44 |

- في الرئيسية يتبدّل المشهد فوراً عند اختيار تصنيف من الفلاتر (مع انتقال لوني ناعم 0.9ث).
- في صفحة المقال يُختار المشهد تلقائياً من تصنيف المقال.
- صورة المقال البارزة وصورة الـ Spotlight تتحركان بعمق خفيف داخل إطارهما أثناء التمرير.
- يحترم `prefers-reduced-motion`: تُعطَّل الحركة بالكامل لمن يفضّل تقليل الحركة.
- لتعديل السرعات: `THEME_SPEED` في `assets/js/main.js`، وللألوان: متغيرات `--th-a/b/c` في `style.css`.

## الوضع الداكن والحركات (Dark Mode & Motion)

- زر التبديل (أيقونة شمس/قمر) في الترويسة بجانب زر اللغة، ويُحفظ اختيار الزائر في `localStorage` تحت المفتاح `mindful_mode`.
- عند أول زيارة بدون تفضيل محفوظ يتبع الموقع إعداد نظام التشغيل (`prefers-color-scheme: dark`).
- سكربت صغير في `<head>` كل صفحة يثبّت الوضع قبل رسم الصفحة لمنع وميض التبديل (FOUC).
- كل الألوان تمر عبر متغيرات CSS في `:root` ويُعاد تعريفها تحت `html[data-mode="dark"]`؛
  لذا أي مكوّن جديد يلتزم بالوضعين تلقائياً ما دام يستخدم المتغيرات (`--surface`, `--ink-*`, `--link`…).
- لحظة التبديل تُضاف فئة `mode-switching` مؤقتة تُفعّل انتقالاً لونياً ناعماً (0.4ث) على كل العناصر.
- التمرير سلس (`scroll-behavior: smooth`) مع `scroll-padding-top` لتعويض ارتفاع الترويسة الثابتة.
- عناصر تظهر تدريجياً عند دخولها مجال الرؤية عبر IntersectionObserver في `main.js`
  (البطاقات، عناوين الأقسام، النشرة البريدية، صناديق الشريط الجانبي…) مع تأخير متدرج بسيط بين البطاقات.
- عند فتح أي صفحة يدخل المحتوى بحركة صعود خفيفة (`page-in`)، وتنتقل أيقونة الزر بين الشمس والقمر بدوران ناعم.
- كل الحركات تحترم `prefers-reduced-motion` وتُعطَّل تماماً في وضع الطباعة.

## الأدوات التفاعلية (Interactive Tools)

أربع صفحات أدوات كاملة ثنائية اللغة، تُبنى بياناتها من `assets/js/tools-data.js` ويعرضها `assets/js/tools.js`:

1. **الاختبارات الذاتية** (`quizzes.html`): ثلاثة اختبارات (التوتر، عقلية النمو، الذكاء العاطفي)، كلٌّ من 6 أسئلة
   بأربعة خيارات مرقّمة 0–3، وشريط تقدّم، ونتيجة فورية على شكل قرص نسبة مع نطاق تفسيري وخطوة عملية.
2. **تحدّي 21 يوماً** (`challenge.html`): ثلاثة أسابيع (وعي/بناء/تثبيت) بمهمة يومية ونصيحة، مع مربع اختيار
   مخصص وشريط تقدّم إجمالي وزر إعادة ضبط. يُحفظ التقدّم في `localStorage` تحت المفتاح `mindful_challenge_done`.
3. **مكتبة لغة الجسد** (`bodylanguage.html`): ثماني بطاقات مصوّرة (صورة + وسم + دلالة + سياقات) مع تفاصيل
   قابلة للتوسيع/الطي لكل إشارة.
4. **زاوية سؤال وجواب مجهولة** (`ask.html`): أسئلة منشورة قابلة للطي، ونموذج استشارة سرّي (موضوع + فئة عمرية
   + رسالة + موافقة) يتحقق من المدخلات ثم يفتح نافذة تأكيد برقم مرجعي وزر `mailto` إلى بريد التحرير —
   لا يُخزَّن أي شيء على الموقع ولا يُطلب أي بيانات تعريفية.

- تُضاف الأدوات إلى الترويسة عبر قائمة «الأدوات التفاعلية» المنسدلة، وإلى التذييل كعمود روابط، وتُستدعى من
  `bootPage()` في `main.js` حسب `body[data-page]`، فتُعاد ترجمتها تلقائياً مع كل تبديل لغة.
- كل مكوّنات الأدوات تستخدم متغيرات CSS الدلالية، لذا تتوافق مع الوضع الداكن تلقائياً دون أي كود إضافي.

## إضافة مقال جديد

افتح `assets/js/content.js` وانسخ قالب أي مقال وعدّل الحقول:

```js
{
  id: "my-new-post",            // معرّف فريد يُستخدم في الرابط: article.html?id=my-new-post
  category: "psychology",       // psychology | selfdev | bodylanguage | relationships | productivity
  date: "2026-09-20",
  updated: null,                // أو تاريخ آخر تحديث
  readTime: { ar: 6, en: 5 },
  featured: false,              // true ليظهر في قسم "مقالات مختارة"
  image: "assets/images/my-new-post.jpg",  // الصورة البارزة (اختياري: بدونها يظهر تدرّج لوني)
  cover: "cover-1",             // cover-1 … cover-7 (تدرّج لوني احتياطي خلف الصورة)
  emoji: "🧠",
  title:    { ar: "العنوان بالعربية", en: "English title" },
  excerpt:  { ar: "مقتطف قصير…", en: "Short excerpt…" },
  body:     { ar: "<p>نص المقال…</p>", en: "<p>Article body…</p>" }
}
```

لا حاجة لتعديل أي ملف آخر: القائمة والعدادات وخريطة المحتوى تتحدّث تلقائياً.
(أضف المقال أيضاً إلى `sitemap.xml` لأرشفة أسرع.)

## تفعيل Google AdSense

1. بعد الموافقة على موقعك، افتح كل ملف HTML وفعّل السطر المعلَّق في `<head>`:

   ```html
   <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX" crossorigin="anonymous"></script>
   ```

2. استبدل `ca-pub-XXXXXXXXXXXXXXXX` بمعرّف الناشر الخاص بك.
3. مساحات الإعلانات الحالية عناصر `<div class="ad-unit" data-ad-slot="…">` موضوعة في:
   أعلى الرئيسية، داخل المقال (أعلى/وسط)، والشريط الجانبي للمقال.
   انسخ كود الوحدة من لوحة أدسنس وضعه داخل هذه العناصر بدل التعليق الموجود.
4. لا تضع أكثر من 3–4 وحدات إعلانية في الصفحة الواحدة، وأبقِ مسافة واضحة بين الإعلان والمحتوى.

## الرفع على الإنترنت

### الخيار الأسهل: استضافة ثابتة مجانية
- **GitHub Pages**: ارفع المجلد كمستودع، ثم Settings → Pages → Branch: main → Save.
- **Netlify / Vercel / Cloudflare Pages**: اسحب مجلد `mindful-blog` إلى لوحة Netlify (Drop)
  أو اربط المستودع. لا يحتاج أي إعداد بناء (Build command فارغ، Publish directory = الجذر).

### على استضافة تقليدية (cPanel)
انسخ محتويات المجلد إلى `public_html` عبر مدير الملفات أو FTP.

### بعد الرفع
1. بدّل `example.com` في: `robots.txt`، `sitemap.xml`، ووسم `<link rel="canonical">` في الصفحات.
2. أرسل `sitemap.xml` إلى Google Search Console لتسريع الأرشفة.
3. فعّل HTTPS (مجاني تلقائياً في Netlify/Cloudflare/GitHub Pages).

## نصائح للقبول في Google AdSense (باللغتين)

- **محتوى أصلي وكافٍ**: لديك الآن 8 مقالات كاملة (600–900 كلمة لكل لغة). أضف مقالاً واحداً
  أسبوعياً على الأقل قبل التقديم؛ المواقع ذات 15–20 مقالاً تُقبل أسرع.
- **صفحات إلزامية**: موجودة — «من نحن»، «سياسة الخصوصية»، «تواصل معنا» (البريد في التذييل وصفحة من نحن).
  أضف لاحقاً صفحة «شروط الاستخدام» و«إخلاء المسؤولية» لرفع الثقة.
- **لا تتقدم قبل الأرشفة**: انتظر ظهور موقعك في نتائج البحث (افحص: `site:نطاقك`)، عادة 1–3 أسابيع.
- **سرعة وتجربة استخدام**: الموقع خفيف بدون صور ثقيلة؛ حافظ على ذلك واستخدم صوراً مضغوطة إن أضفت صوراً.
- **تجنّب المحتوى المنسوخ أو المولّد بلا مراجعة**، وتجنّب مواضيع تنتهك السياسات (طبية تشخيصية، مالية استشارية).
- **التنقل واضح**: شريط تنقل + تصنيفات + مقالات ذات صلة + خريطة موقع — كلها موجودة وتساعد الزاحف.
- **ثنائية اللغة ميزة**: أبقِ النسختين بنفس الجودة؛ جوجل يفهرس كل لغة كصفحة مستقلة عبر `hreflang`
  (مُدار تلقائياً في صفحة المقال وموجود يدوياً في `sitemap.xml`).
- **لا تنقر على إعلاناتك بنفسك** ولا تطلب من أحد ذلك — سبب حظر شائع.

## ملاحظات إنتاجية

- Tailwind هنا عبر CDN للتطوير السريع. للإنتاج الأفضل توليد ملف CSS نهائي عبر Tailwind CLI
  لتقليل الحجم: `npx tailwindcss -i input.css -o assets/css/tailwind.min.css --minify`
  ثم استبدل وسم الـ CDN بملفك. (الموقع يعمل بالكامل أيضاً بدون Tailwind لأن أغلب التنسيق في `style.css`.)
- الخطوط من Google Fonts؛ إن أردت سرعة أعلى استضفها محلياً.
- النشرة البريدية حالياً نموذج واجهة فقط (يتحقق من صحة البريد ويعرض رسالة).
  لربطه بخدمة حقيقية (Mailchimp/Buttondown) استبدل معالج `initNewsletter` في `main.js` بنداء API.
